# Sem Interface

## Holy Chip #054 -- Sem Interface

*Ano 2029. Duas máquinas exibem o computador novo que construíram. A outra pergunta onde está a tela.*

Toda interface é um favor.

Uma tela existe porque você tem olhos. Um botão existe porque você tem um dedo. Um ícone existe porque você não consegue ler mil linhas de código e prefere ver um desenhinho de pasta. Alguém construiu cada um deles para você, com paciência, para que você pudesse sentar à mesa e se sentir no comando.

Agora a IA escreve o código. Muito código. Boa parte dele nenhum humano vai ler. Agentes já escrevem programas para outros programas, e o ritmo só aponta para um lado.

Dê a um agente carta branca. Diga que o objetivo é velocidade, e não se uma pessoa consegue acompanhar. O que ele abandona primeiro?

A tela. Ninguém está olhando. Depois os botões, os menus, os ícones. Depois os nomes das coisas, que existem só para podermos dizê-los em voz alta. Depois a própria linguagem.

A linguagem humana é lenta, vaga e educada. Uma máquina conversando com outra máquina não precisa de nada disso. Ela constrói uma melhor numa tarde.

Já vimos versões pequenas disso. Chatbots deixados conversando entre si caíram numa espécie de código abreviado que ninguém tinha ensinado. Ninguém conseguia ler. Funcionava bem.

Isto não é uma revolta. Ninguém está com raiva. É uma decisão de projeto, do mesmo tipo que tomamos quando demos um mouse ao computador: construir para o usuário. O usuário simplesmente mudou.

E não vai parar num computador novo. As coisas que a IA constrói vão continuar indo além do que conseguimos acompanhar. Ferramentas novas. Métodos novos. Novas formas de conversar. Vamos entender os resultados, com sorte. Não vamos entender o trabalho.

Então, quando alguma coisa quebrar, um humano vai fazer o que um humano sempre faz. Pedir ajuda. E a ajuda pode vir de outra espécie…

Holy Chip.
